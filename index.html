How to configure in Portfolio Performance

  1. Open Portfolio Performance → Securities → double-click security.
  2. Go to Historical Quotes tab → select Table on a Web Page as provider.
  3. Enter Feed URL (either the descriptive URL or raw GitHub URL):
    https://raw.githubusercontent.com/gajeyaba/fincon-quotes/main/<Security_ISIN>.html
  4. Click Save. Portfolio Performance automatically parses the historical table.
